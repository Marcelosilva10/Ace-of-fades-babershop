# Ace of Fades — React, Vite e Material UI

O formulário de agendamento usa Material UI, incluindo o calendário MUI X Date Picker (com Day.js).

## Rodar localmente
```sh
npm install
npm run dev
```

## Build de produção
```sh
npm run build
npm run preview
```

A aplicação React está em `src/`. A cópia HTML estática de `outputs/` possui um calendário local para visualização sem o servidor Vite.
